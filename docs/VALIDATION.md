## 为移动端实施的处理

- 窄屏采用单列布局，三维视图约 245–280px 高。
- 物体列表允许横向滚动，避免页面整体横向溢出。
- 主要按钮、发送、相机与弹窗关闭按钮采用至少约 44px 的触控目标。
- 输入字号 16px，减少 iOS 输入时的自动缩放；底部考虑 safe-area。
- 提供“输入指令”和“查看世界”的页面内跳转。
- 支持 OrbitControls 的触控旋转和双指缩放；弹窗最大高度使用动态视口单位。
- 支持 reduced-motion；以原生按钮和 Base UI 管理基本焦点/弹窗语义。

这些是已实现的响应式处理，不能替代上述未完成的真机验证。

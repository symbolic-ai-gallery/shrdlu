# 验证记录

遵照“不做过度测试”的要求，每轮只验证直接受影响的路径，不重复整套测试或开展性能基准。

## 本次：中英文句式与词汇扩展

- 新增独立英文规范化层，覆盖常见礼貌包装、缩写、动作／物体／颜色／尺寸／空间关系同义词。
- 中文组合转换新增普通宾语句、位置前置句、关系名词短语、拿放与堆叠同义表达，以及包含、支撑、存在、关系、数量和比较查询。
- 增加英文关系／比较／列举问句和拿取、移出、放下、移动等动作句式，并扩充常见中文回答本地化。
- `pnpm test` 通过：2 个测试文件、53 项测试，包括原有中英文各 43 轮回归、19 组新增中文组合转换、英文同义词、双语状态等价、中文生成句式执行和回答翻译。
- `pnpm build` 通过：上游引擎生成、严格 TypeScript 检查和 Vite 生产构建均成功。

## 上一轮：主题、输出目录与底部输入栏

- `pnpm add react-bottom-fixed` 安装 0.2.0，检查实际 ESM 实现、样式和类型声明，接入输入表单。
- TypeScript 严格检查及生产构建通过，产物生成在 `docs/`；原文档完整迁至 `documents/`，审计脚本和 README 引用已更新。
- 浏览器打开实际构建产物 `/docs/#/lab`，Worker 与 XML 成功加载，提交盒内物体查询并得到实时回答，确认子路径下的资源加载。
- 检查入口页与实验台暗色画面；通过按钮切换为浅色并刷新，选择保持；进入实验台再次切换为暗色。
- 桌面 1440×900 布局稳定后输入框底部为 872px，非 iOS 容器为普通相对定位。暗色菜单背景与文字分别为 `rgb(20, 20, 20)` 和 `rgb(237, 237, 237)`。
- Chromium 模拟 iPhone 用户代理与 390×844 视口，确认输入栏实际使用 `BottomFixed` Portal，输入框底部为 822px，无横向溢出。
- 聚焦输入框后，临时模拟 `visualViewport.height = 480` 并触发 resize：容器只上移 364px，输入框底部为 458px，实验台高度为 480px，对话区保留 89px 输入栏位置。恢复后可正常提交。这是合成事件检查，不是 iOS Safari 真机验证。
- 本轮不涉及语言与规划逻辑，没有重跑引擎测试。

## 更早：界面与机械臂

- TypeScript 严格检查、Vite 生产构建和 `git diff --check` 通过。
- 执行 3 个测试：完整 43 轮英文流程及几何断言、清障与抓放阶段及持物偏移、双连杆在可达位置的长度约束。全部通过，其余 19 个已有测试未重跑。

## 尚未测试或仍有限制

- iOS Safari、Android Chrome 真机的触控、软键盘、安全区域和方向切换。
- 完整桌面浏览器矩阵、全部菜单操作、长时间运行和低性能设备。
- 200% 文本放大、屏幕阅读器及完整 WCAG 审核。
- WebGL 上下文丢失、后台恢复及极端断网条件。
- WebMCP 工具的完整端到端执行。
- 上游回退动作没有统一转换成领域规划器的八类动作阶段；完整机械臂碰撞规划、质量和动力学没有实现。
- 任意英文改写、全部量词和否定组合、开放式概念学习与完整中文自然语言覆盖。

## 界面依据

参考 [Vercel Web Interface Guidelines](https://vercel.com/design/guidelines)、[shadcn/ui](https://ui.shadcn.com/docs) 和 [Base UI Menu](https://base-ui.com/react/components/menu)：精简常驻操作、辅助功能按需展开、输入框保持在可见区域、移动输入字号 16px、主要触控目标 44px、提供焦点样式和手势之外的相机按钮。组件仍使用用户指定的 Base UI。
